# serotonin-scripts

Public release repo for finished Serotonin Lua scripts. Development takes place in the private [serotonin-dev](https://github.com/mixercodes/serotonin-dev) repo — don't edit scripts here directly.

Scripts are written for the [Serotonin](https://serotonin.win/) Lua scripting API for Roblox.

- https://serotonin-ref.vercel.app — runtime-verified, 17 libraries, 130+ functions
